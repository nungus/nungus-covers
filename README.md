# Chiptune covers
Exported versions of my chiptune covers of video game music in .nsf/.vgm format.

All arrangements published on my [YouTube channel](https://www.youtube.com/@thenungus) are present here.<br>
I currently intend to upload formatted files for all future covers, but it isn't guaranteed.

Playing on real hardware isn't a focus of these covers - they may make use of enhanced tracker features. Some tracks use many samples, causing a larger file size (e.g. Hammer of Justice), which could affect compatibility or be impractical relative to typical cartridge sizes.
